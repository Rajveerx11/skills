# LinkedIn learnings — Rajveer

## What wins for this user (ranked, update as results land)
1. **Human narrative / pain-led hook** beats feature-dump. Evidence: narrative post 485
   impressions vs buzzword "infrastructure layer" post 232. Lead with a real frustration.
2. Narrow > comprehensive. One sharp idea per post; deliver features as the payoff, not a list.
3. First-person voice. **HARD RULE: repo link ALWAYS in the first comment, NEVER in the post body/description.** (User stated this explicitly 2026-06-12.)
4. User prefers **longer posts** with an origin-story arc — e.g. open with "A few months back I started/created a project..." then build to the payoff. BUT: on 2026-06-17 (flaky-feature post) he asked to "make it more crisp and shorter" — so read the moment; default to richer arc for launches/origin stories, go tight/punchy for single-feature announcements. When in doubt, offer both lengths.
